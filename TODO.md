# GameVault - Next-Gen Video Game & Gaming Gear Store

## Project Overview
Fullstack e-commerce platform for video games, consoles, pro gaming gear, and digital keys.

### Converted Components:
- [x] Product schema updated with gaming fields (platform, genre, developer, publisher, age rating, edition).
- [x] Backward-compatible schema fields (size -> edition, brand -> publisher, etc.).
- [x] High-resolution game catalog (PS5, Xbox Series X, PC Games, Nintendo Switch, Consoles & Gear).
- [x] Order management and UPI checkout (`gamevault@upi`).
- [x] Frontend design transformed with dark gaming cyberpunk aesthetics.
- [x] Gamer authentication, cart with game edition selection, and order history.
- [x] Admin dashboard with gaming category and inventory controls.
